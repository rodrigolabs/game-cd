# Game - O Jogo

## Visão geral

O jogo consiste em um cenário tipo um centro de distribuição. Esse centro de distribução (CD) tem vários corredores e prateleiras, uma área de caixa (para faturamento) e uma área de doca para despachar as caixas.

De tempos em tempos um novo pedido aparece para o jogador separar. Pegando os itens do pedido, juntando em uma caixa e levando para a área de faturamento (caixa). Nesta etapa o caixa emite a nota fiscal e o jogador deve levar a caixa para a doca para o pedido ser despachado.

Cada pedido, pode ter um ou mais itens. Os itens disponíveis são:

- Quadrado azul
- Triângulo verde
- Bola vermelha
- Bola amarela
- Entre outras formas geométricas cada uma de uma cor

O pedido aparece, e o jogador tem um tempo para atender o pedido, separando todos os itens, levando para o caixa e depois para a doca.

Outros pedidos podem ir aparecendo, cada um com um tempo de atendimento que o jogador deve cumprir.

Se o jogador não separar e entregar na doca a tempo, ele é punido e não ganha os pontos e perde 1 de energia.

Se peder 5 energias é game over.
